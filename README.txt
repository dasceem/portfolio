# Как задеплоить на Vercel

## Шаг 1 — GitHub
1. Зайди на github.com (регистрация за 30 секунд)
2. Нажми зелёную кнопку "New" (создать репозиторий)
3. Назови: portfolio-dasceem
4. Нажми "Create repository"
5. Нажми "uploading an existing file"
6. Перетащи сюда файл index.html
7. Нажми "Commit changes"

## Шаг 2 — Vercel
1. Зайди на vercel.com
2. Нажми "Add New..." → "Project"
3. Нажми "Import" рядом со своим репозиторием portfolio-dasceem
4. Нажми "Deploy" (настройки не трогай)
5. Через 20 секунд получишь ссылку!

## Готово!
Ссылка будет вида: https://portfolio-dasceem.vercel.app
Кидай её клиентам — открывается на любом телефоне.
